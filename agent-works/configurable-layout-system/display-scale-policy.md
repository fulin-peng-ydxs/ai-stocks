# 界面比例与自动缩放策略

## 文档边界

本文维护自动比例公式、尺寸档案匹配、用户偏好同步及配置验证契约。共享布局与视觉约束见 [DESIGN.md](../../DESIGN.md)，布局与外观的整体装配见 [前端布局实现](../architecture/frontend-layout.md)，环境变量和配置覆盖层见 [环境配置架构](../architecture/environment-configuration.md)；本文不定义页面响应式断点，也不记录各页面实测结果。

策略变更须同步 `frontend/src/layout/displayScalePolicy.ts`、`displayScaleProfiles.ts`、`frontend/src/composables/useDisplayScale.ts`、配置消费方及对应前后端测试；页面与组件适配证据分别更新 [页面检查](responsive-pages.md) 和 [组件清单](responsive-components.md)，不得用缩放策略代替响应式实现。

## 自动比例

自动缩放指数是系统外观配置 `ui.display.auto_scale_exponent`，默认 `0.10`，范围 `0～1`。它不属于视觉预设，切换颜色或圆角预设不得改变界面比例策略。

计算为 `round(100 × (屏幕可用 CSS 面积 / (2560 × 1440)) ^ 指数)`，结果限制在 90%～110%。指数为零时自动比例保持 100%。1920×1080 可用面积在默认指数下为 94%，2560×1440 为 100%，3360×1890 为 106%。

## 自定义尺寸档案

- 用户调整自定义比例时保存 `{width, height, percent}`；尺寸来源与自动模式相同，不使用物理像素、DPR、设备名称或浏览器窗口尺寸。
- 当前宽高均在档案 `±15%` 内时采用综合相对距离最近的档案；`5%` 内重复调整更新原档案，无匹配时回退最近一次自定义比例。
- 从自动切到自定义时继承当前自动比例并保存当前尺寸档案；恢复 100% 同样更新当前档案。
- 档案随既有 `display-scale` 全局用户偏好同步到 PostgreSQL；旧偏好没有档案时保持原 `customPercent` 行为。

## 配置闭环

- 系统设置表单由 `backend/storage/app_config.py` 元数据驱动，沿用现有系统设置权限、API、审计和 `app_config` 覆盖层。
- 后端只接受范围内有限数值，拒绝布尔值、无法转换的字符串、越界和非有限数值。
- 登录公开配置以独立字段 `auto_scale_exponent` 下发，登录前后共用；本地安全缓存用于接口暂时不可用时的首屏恢复。
- 历史预设字段在幂等迁移中导入该系统配置；优先使用启用的内置预设值，缺失时使用 `0.10`。

## 验证

- 前端覆盖自动比例、非法值回退、手动模式隔离、尺寸档案匹配与首屏缓存恢复。
- 后端覆盖元数据默认值、值域校验、公开读取白名单和旧预设迁移。
