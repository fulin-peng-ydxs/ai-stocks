# 响应式页面检查

本清单记录各页面布局验收的日期、观察状态、结论与覆盖缺口，用于选择复测范围。

参考：[设计规范](../../DESIGN.md) · [组件适配清单](responsive-components.md) · [页面实施模板](page-template.md)。

## 证据口径

- **全站基线：2026-10-07。** 表中页面均有入口布局检查记录，后续只对列明的页面和状态做局部复核；较早的通过记录不代表当前版本所有业务状态已重新验证。
- 标准浏览器视口：V1＝1100×620、V2＝1366×768、V3＝1440×900。基线与早期局部复核使用自动界面比例约106%，后续复核比例按具体条目记录；这些是浏览器视口，布局画布由应用缩放折算，不作为组件断点值；提示机制另以1280×720、当时自动比例局部复核，下拉面板另含390×844窄屏复核，单独登记，不代表V1–V3已重新复测。
- 实测入口为5181内置浏览器；用户授权的其他浏览器复核单独登记。已有入口检查使用 `debug_normal` / `debug_system`，回测、训练和交易日修订的写入验收使用独立临时普通用户；具体范围见页面详情。草稿编辑与取消不计为保存，真实运行、模拟成交或记录保存只按明确列出的状态计入；不由入口检查推断完整业务链路通过。
- “入口通过”只覆盖表中已观察状态的主操作可达、溢出和滚动；“局部通过”仅覆盖注明的复核项。单测和源码扫描另行提供证据，不能代替浏览器结论。
