# 响应式页面检查

## 文档边界

本文件维护各页面当前可用的布局验收证据及覆盖缺口，用于选择后续复测范围。设计要求见 [DESIGN.md §8](../../DESIGN.md#8-响应式行为)，组件适配策略见 [响应式组件触发清单](responsive-components.md)，实施与验收流程见 [页面模板](page-template.md)。字体、颜色和动效规则统一查阅 DESIGN，不在此重复定义。

页面布局或验收范围变化时更新对应行的日期、状态、结论与未验证项；源码覆盖由组件清单维护，业务规则及性能测试由对应模块文档和测试承载。本文是有时间与状态范围的证据清单，不代表所有页面当前版本全部验收通过。

全组件边界专项局部复核（2026-10-23）：系统组件页真实样板完成浅/深焦点、错误与禁用组合、网格1/2/3列/跨列和结果三态保框；菜单与系统配置V1核对普通面板/图标/折叠，字典V3核对Dialog外沿与textarea焦点，提交前另于默认视口复测浅/深主题的深底Popover及禁用范围底色；未改变页面布局与slot。完整证据和未覆盖边界见[边框实施结果](border-unification/audit.md#本次验证与边界)，不将全量静态门禁当作全页面浏览器通过。

## 证据口径

- **全站基线：2026-10-07。** 表中页面均有入口布局检查记录，后续只对列明的页面和状态做局部复核；较早的通过记录不代表当前版本所有业务状态已重新验证。
- **最近局部复核：2026-10-26。** 该日期只代表注明范围的实际复核；未登记的日期、主题或状态不补写为已通过。
- 标准浏览器视口：V1＝1100×620、V2＝1366×768、V3＝1440×900。基线与早期局部复核使用自动界面比例约106%，后续复核比例按具体条目记录；这些是浏览器视口，布局画布由应用缩放折算，不作为组件断点值；提示机制另以1280×720、当时自动比例局部复核，下拉面板另含390×844窄屏复核，单独登记，不代表V1–V3已重新复测。
- 默认实测入口为专用5181内置浏览器，用户明确授权的原浏览器复核单独登记在页面条目；业务页使用 `debug_normal`，系统/数据页及最近局部复核使用 `debug_system`。仅查看页面和操作界面状态，未为验收创建正式规则或发起采集、筛选、回测等业务写任务。
- “入口通过”只覆盖表中已观察状态的主操作可达、溢出和滚动；“局部通过”仅覆盖注明的复核项。单测和源码扫描另行提供证据，不能代替浏览器结论。
