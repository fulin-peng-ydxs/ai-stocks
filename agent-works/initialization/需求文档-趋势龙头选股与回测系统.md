## 1. 项目背景

### 1.1 问题陈述
现有看盘软件（同花顺、通达信、TradingView）能做条件选股，但存在三个痛点：
1. **筛选条件难以自由组合与持久化**：想把"两年新高 + 多头排列 + 放量突破 + RS 强度前 5%"这种多维组合保存、复用、批量跑全市场，并不顺手。
2. **缺少量化打分**：选出来一堆票，无法按"上涨概率"排序，只能人工逐个看。
3. **没有严谨回测**：无法回答"这套筛选/打分规则，在过去 N 年里到底赚不赚钱、胜率多少、回撤多大"。

### 1.2 解决思路
构建一个**本地化、可复现、可回测**的选股系统：
**存数据 → 算指标 → 按指标组合筛选并分类 → 打分排序 → 回测验证 → 输出可执行的观察池**。

核心假设（需被回测验证，而非默认成立）：

> **具备"趋势龙头"特征（位置高、趋势强、放量突破、强于大盘）的股票，在筛选时点之后的一段持有期内，上涨的概率与幅度显著高于市场基准。**

本系统的根本目的，就是用数据去**验证并量化**这个假设，并据此每日输出"上涨概率最高"的候选股票。

### 1.3 灵感来源
对宝鼎科技、光华科技、得邦照明等主升浪个股的形态归纳：
`长期横盘蓄势 → 放量突破平台 → 均线多头排列 → 主升浪加速 → 沿 5 日线趋势上涨`。
系统的目标之一是**尽可能提前、批量地**发现这类形态的股票。

## 2. 目标与非目标

### 2.1 业务目标（Goals）

| 编号 | 目标 | 可衡量结果 |
|------|------|-----------|
| G1 | 本地完整存储 A 股行情与基础数据 | 全市场日线数据完整、可增量更新、可追溯 |
| G2 | 把"趋势龙头"特征转化为可计算、可配置的指标库 | 第 6 章所有指标均可程序化计算并落库 |
| G3 | 支持任意指标组合的筛选与分类 | 用户可自定义、保存、复用筛选方案，并批量跑全市场 |
| G4 | 对候选股票打分排序，输出"上涨概率最高"的 Top N | 每日收盘后产出评分榜单 |
| G5 | 提供严谨回测，验证筛选/打分规则的有效性 | 可输出胜率、盈亏比、年化、最大回撤、夏普等指标 |
| G6 | 识别买点与风险，形成可执行观察池 | 标注第一/第二/第三买点与风险预警 |

### 2.2 非目标（Non-Goals，本期明确不做）
- ❌ 不做自动下单 / 实盘交易（远期第三阶段再议）。
- ❌ 不做高频 / 日内 tick 级策略（本期为日线 EOD）。
- ❌ 不做面向他人的 SaaS、多租户、对外荐股服务。
- ❌ 不做基本面深度估值模型（仅保留少量基本面过滤字段，如市值、行业）。
- ❌ 不做投资建议输出（只输出"评分/概率/形态标签"这类客观结果）。

## 3. 范围（Scope）

### 3.1 市场与标的范围
- **本期**：A 股**主板（沪/深）+ 创业板 + 科创板**；**不含北交所**（流动性弱、涨跌幅 30% 与数据口径差异，本期排除；架构预留开关）。
- **过滤项可配**：是否剔除 ST/\*ST、是否剔除上市不足 N 天的次新股、是否剔除停牌股、是否限定流通市值区间。
- 科创板涨跌幅为 ±20%（与主板 ±10% 不同），数据质量与回测约束需按板块区分（见 F-DQ-04）。
- **远期扩展**（不在本期，但架构应预留）：指数/ETF、港股、美股。

### 3.2 数据时间粒度
- **本期**：日线（含每日开高低收、成交量额、换手率、复权因子等）。
- **预留**：周线/月线（可由日线聚合）、未来分钟线。

### 3.3 时效性
- **本期**：T+1，收盘后（约每日 18:00 后数据稳定）批量计算，次日开盘前可用。
- **远期**：盘中准实时（依赖 QMT 等数据源，第二阶段）。

## 4. 术语表（统一口径）

| 术语 | 定义 |
|------|------|
| **EOD** | End of Day，收盘后批量处理模式 |
| **复权** | 对除权除息造成的价格跳变进行还原；分**前复权**（以最新价为基准）、**后复权**（以上市价为基准）、**不复权** |
| **OHLCV** | 开(Open)/高(High)/低(Low)/收(Close)/量(Volume) |
| **HHV(H,N)** | 最近 N 个交易日内最高价的最大值 |
| **MA(X,N)** | X 的 N 日简单移动平均 |
| **REF(X,N)** | X 在 N 个交易日之前的值 |
| **COUNT(条件,N)** | 最近 N 日内满足条件的天数 |
| **多头排列** | 短期均线在长期均线之上且依次向上排列（如 MA5>MA10>MA20>MA60） |
| **RS 强度（相对强度）** | 个股相对市场/基准的强弱排名，常以百分位表示（RS95 = 强于 95% 个股） |
| **换手率** | 当日成交量 / 流通股本 |
| **流通市值** | 流通股本 × 收盘价 |
| **观察池/自选池** | 系统筛选并打分后输出的候选股票集合 |
| **买点** | 系统识别出的、风险收益比相对较优的介入时机（非交易指令） |
| **未来函数（Look-ahead Bias）** | 计算某日指标时错误使用了该日之后才能知道的数据，导致回测虚高 |
| **幸存者偏差（Survivorship Bias）** | 回测样本只含至今仍存续的股票，剔除了已退市股，导致结论偏乐观 |
| **过拟合（Overfitting）** | 规则/参数过度贴合历史数据，样本外失效 |
| **滑点（Slippage）** | 实际成交价与理论价的偏差 |
| **基准（Benchmark）** | 衡量超额收益的参照，如沪深 300、中证 500、中证全指(000985) |
| **持有期 / Holding Period** | 回测中买入后持有的交易日数 |
| **再平衡 / 调仓周期** | 回测中重新筛选并调整持仓的频率 |

## 6. 指标体系详细定义（核心）

> 说明：以下为"趋势龙头"特征的可计算定义。所有 `N`、倍数、区间均为**默认值且可配置**。技术指标默认基于**前复权**价格。公式沿用通达信式表达，仅作语义定义，不限定实现。

### 6.1 位置维度（个股处于高位、套牢盘少、上方阻力小）

| 指标 | 定义 | 默认参数 | 说明 |
|------|------|---------|------|
| 两年新高 | `C >= HHV(H, N)` | N=480 | 收盘价创约两年新高 |
| 一年新高 | `C >= HHV(H, N)` | N=240 | |
| 120 日新高 | `C >= HHV(H, N)` | N=120 | |
| 60 日新高 | `C >= HHV(H, N)` | N=60 | |
| 距新高幅度 | `(HHV(H,N) - C) / HHV(H,N)` | N=480 | 衡量"接近新高"的程度，可做连续值打分 |

> ⚠️ 次新股不足 N 天时，长周期新高指标应判为**不适用**（不得用上市以来最高价冒充 N 日新高）。

### 6.2 趋势维度（均线多头、方向向上）

| 指标 | 定义 | 默认参数 |
|------|------|---------|
| 多头排列 | `MA5 > MA10 > MA20 > MA60` | 5/10/20/60 |
| 均线向上(20) | `MA20 > REF(MA20, K)` | K=5 |
| 均线向上(60) | `MA60 > REF(MA60, K)` | K=5 |
| 连续站稳 60 日线 | `COUNT(C > MA60, K) = K` | K=5 |
| 站上年线 | `C > MA250` | 250 |

### 6.3 突破维度（脱离平台、突破有效）

| 指标 | 定义 | 默认参数 |
|------|------|---------|
| 放量突破 | `VOL > MA(VOL, N) * X` | N=20, X=2 |
| 平台突破 | `C > REF(HHV(H, N), 1)`（突破此前 N 日平台高点） | N=60 |
| 突破保持 | `COUNT(C > HHV(H, N), K) >= M` | N=60, K=5, M=4 |
| 横盘蓄势（前置） | 突破前一段时间振幅收敛（如 N 日内最高/最低 < 阈值） | 可配 |

> 注：`平台突破` 用 `REF(HHV(H,N),1)` 而非 `HHV(H,N)`，避免把"当天自己"算进平台高点造成逻辑自洽的伪突破——这是防未来/自指的细节。

### 6.4 成交量维度

| 指标 | 定义 | 默认参数 |
|------|------|---------|
| 启动放量 | `VOL > MA(VOL, N) * X` | N=20, X=2 |
| 持续放量 | `MA(VOL, S) > MA(VOL, N) * Y` | S=5, N=20, Y=1.5 |
| 量价齐升 | 放量同时收阳/创新高 | 组合条件 |

### 6.5 换手率维度

| 指标 | 定义 | 默认区间 |
|------|------|---------|
| 健康换手 | `3% <= 换手率 <= 20%` | 黄金区间 |
| 换手过低（剔除） | `换手率 < 1%` | 流动性不足 |
| 换手过高（风险） | `换手率 > 35%` | 过热/出货风险 |

### 6.6 相对强度（RS）维度

| 指标 | 定义 | 默认 |
|------|------|------|
| RS 强度 | 个股区间涨幅在全市场中的百分位排名 | 取前 5%（RS95+）|
| RS 计算窗口 | 用于排名的涨幅回溯期 | 可配（如 60/120 日） |
| 强于基准 | 个股区间收益 > 基准（沪深300/中证500）区间收益 | — |

> 需明确：RS 是**横截面排名指标**，计算时需用全市场当日数据做百分位；务必保证只用 ≤T 日数据。

### 6.7 市值 / 流动性维度

| 指标 | 定义 | 默认 |
|------|------|------|
| 流通市值区间 | `50 亿 <= 流通市值 <= 400 亿` | 可配 |
| 日均成交额下限 | `MA(成交额, N) >= 阈值` | 防流动性陷阱 |

### 6.8 过滤维度（一票否决/排除项）

| 指标 | 说明 |
|------|------|
| 剔除 ST/\*ST | 可配开关 |
| 剔除次新股 | **硬剔除**上市 < 60 个交易日的票；上市 < 480 日时仅令长周期指标（两年新高等）"不适用"，不剔除整票（见 §6.1 注） |
| 剔除停牌 | 当日停牌不入选 |
| 剔除一字涨停 | 当日一字板买不进，可选剔除 |
| 北交所开关 | 是否纳入 |

### 6.9 买点定义（形态序列）

| 买点 | 定义（语义） |
|------|------|
| 第一买点（最佳） | 平台突破成立后 → 缩量回踩至 MA10/MA20 附近且不破 → 重新放量上涨确认 |
| 第二买点 | 放量突破平台当日 |
| 第三买点 | 创历史/阶段新高当日 |
| 规避 | 连续 ≥N 根大阳线后追高 / 量价背离 |

## 7. 评分模型需求

### 7.1 总体要求
- **评分目标已明确**：综合分越高，应代表"**买入后 N 个交易日内最高涨幅 ≥ X%**"的概率越高（**主口径 N=20、X=10%**，并跑 N∈{5,10,20,60}、X∈{10%,20%,30%} 多档对比）。这是评分模型要逼近的目标变量，也是回测的验证口径。
- 综合分范围 **0~100**，由多个维度子分加权求和（默认权重见下表，**全部可配**）。
- 每个维度既支持**布尔式打分**（满足给满分），也应支持**连续式打分**（越接近理想值得分越高），具体方式可配。
- 必须输出**分项得分**，保证可解释。

### 7.2 默认权重（来自讨论，可配）

| 维度 | 默认分值 | 评分依据（示例） |
|------|---------|-----------------|
| 位置（新高） | 30 | 两年新高满分，按距新高幅度递减 |
| 均线趋势 | 20 | 多头排列 + 均线向上 |
| 成交量 | 20 | 启动放量 + 持续放量 |
| 换手率 | 10 | 落在 3%~20% 黄金区间得分高 |
| RS 强度 | 10 | RS 百分位越高分越高 |
| 资金流 | 10 | 主力/北向净流入（依赖 F-DAT-09，缺数据时该维度可置 0 或重新归一化权重） |

### 7.3 分档（阈值可配）

| 分档 | 含义 |
|------|------|
| ≥ 80 | 观察 |
| ≥ 90 | 龙头候选 |
| ≥ 95 | 主升浪核心 |

### 7.4 评分模型的有效性要求
- 评分模型**不能只凭主观设定就上线**，必须通过第 9 章回测（尤其 F-BT-08 分层测试）验证："高分组后续收益/胜率显著高于低分组与基准"。
- 若分层测试不成立（高分组不优于低分组），需视为模型无效，回炉调整。
- **核心验证口径**：回测须统计各评分分档"买入后 N 日内涨幅 ≥ X% 的命中率"，确认分越高、命中率越高，即"达到指定涨幅的概率"随评分单调上升。
- **必须对比基准命中率（关键，易漏）**：分档命中率要与"**同期全市场无条件命中率**"（即随机/任意一只票在 N 日内涨幅 ≥ X% 的概率）对比。只有显著高于这个**基准命中率（base rate）**，才说明评分有真实选股能力，而非沾了当期普涨的光。无此对比，"命中率 55%" 这种数字毫无意义。
- 命中率统计需标注**样本量**，样本过小（如某分档全期仅几十次信号）的结论不予采信。

## 8. 筛选与分类引擎需求（核心中的核心）

### 8.1 设计原则
本系统区别于普通看盘软件的关键在于：**筛选条件是一等公民**——可组合、可命名、可保存、可版本化、可对历史任意日运行、可直接进入回测。

### 8.2 功能要求
1. **条件原子**：每个指标（第 6 章）是一个可独立开关、可设参数的筛选原子，输出布尔或数值。
2. **逻辑组合**：原子之间支持 `AND / OR / NOT` 与嵌套分组，形成复合筛选表达式。
3. **数值比较**：支持对连续指标设阈值（`>`, `>=`, 区间 `between` 等）。
4. **不适用（NULL）语义**：当某指标对该股当日"不适用"（如次新股不足 480 日无法算两年新高），需明确该条件判定规则——**默认 NULL 视为"不满足"该条件**（即该票该日不命中含此条件的方案），可在方案级配置为"忽略该条件"。此规则必须显式，避免 NULL 被静默当成 True/False 造成错选。
4. **筛选方案（Profile）**：一组条件 + 参数 + 逻辑，可命名保存（如"趋势龙头v1"）。
5. **预设方案**：内置常用画像——趋势龙头、平台突破、多头排列、两年新高、回踩 MA20 买点等。
6. **批量运行**：对全市场或指定股票池，在**指定交易日**运行某方案，输出命中列表 + 命中明细。
7. **历史可回溯运行**（关键）：能"回到任意历史交易日"，仅用当时可得数据筛选——这是连接筛选与回测的桥梁。
8. **版本化**：方案修改留痕，便于对比不同版本回测表现。

### 8.3 与其它模块的关系
```
指标库 ──> 筛选引擎(命中票池) ──> 评分模型(打分排序) ──> 观察池/榜单
                  │
                  └────────────────────────────> 回测引擎（对历史每个调仓日重复"筛选→打分→建仓"）
```

## 9. 回测需求（验证核心假设）

### 9.1 回测目的
回答三个问题：
1. **有效性**：按某筛选方案/评分模型选出的股票，持有一段时间后，收益与胜率是否显著优于基准？
2. **分层单调性**：评分越高，后续收益是否越高？（验证打分的意义）
3. **稳健性**：换参数、换时间段，结论是否依然成立？（防过拟合/防偶然）

### 9.2 可配置参数

| 参数 | 说明 | 默认 |
|------|------|------|
| 回测区间 | 起止日期 | 近 5 年 |
| 选股频率/调仓周期 | 每日/每周/每月重选 | 每日选、按持有期持有 |
| 持有期 | 买入后持有交易日数（可多档对比，如 5/10/20/60 日） | 多档 |
| 持仓数量 | 每期最多持有 Top N | 20 |
| 初始资金 | 回测起始本金（决定整手取整与可买数量） | 100 万 |
| 整手约束 | 按 100 股整手买入 | 开启 |
| 单行业持仓上限 | 同一行业最多持仓占比（防扎堆热门板块） | 可选，默认关闭 |
| 买入价 | 命中次日开盘 / 收盘 | 次日开盘 |
| 卖出规则 | **默认"跌破均线卖出"（默认跌破 MA20，周期可配）**；可叠加固定持有期到期卖、止盈止损 | 跌破 MA20 卖 |
| 资金分配 | 等权 / 按分数加权 | 等权 |
| 涨幅命中口径 | 衡量信号质量：买入后 N 日内最高涨幅 ≥ X% | 主 N=20/X=10%，多档 N∈{5,10,20,60}、X∈{10%,20%,30%} |
| 基准 | 超额收益对照 | 主：中证 500；并列沪深 300、中证全指(000985) |

### 9.3 真实性约束（必须满足，否则结论失真）

| 约束 | 说明 |
|------|------|
| 防未来函数 | T 日选股只用 ≤T 日数据；买入用 T+1 价格 |
| 防幸存者偏差 | 回测样本必须含**当时存在、后来退市**的股票 |
| 涨跌停约束 | **开盘价达涨停价无法买入、达跌停价无法卖出**，需顺延或跳过；涨跌停价按板块（主板±10%/科创创业±20%/ST±5%）算 |
| 整手约束 | 买入按 100 股整手取整，余资金不强行满仓 |
| 停牌约束 | 停牌期间不能买卖，持仓停牌按规则处理 |
| 交易成本 | 佣金（双边，可配，默认万 2.5，最低 5 元）+ 印花税（卖出千 1，可配）+ 过户费 + 滑点（可配，如 0.1%~0.3%） |
| 复权一致 | 回测全程使用一致的复权口径 |

### 9.4 输出指标

| 类别 | 指标 |
|------|------|
| 收益 | 累计收益、年化收益、相对基准超额收益 |
| 风险 | 最大回撤、回撤持续期、年化波动率 |
| 风险调整 | 夏普比率、卡玛比率、索提诺比率 |
| 交易统计 | 总交易笔数、胜率、盈亏比、平均单笔收益、平均持有天数、换手率 |
| 分层 | 按评分分档（80/90/95）分别统计后续收益、胜率，以及**"N 日内涨幅 ≥ X% 的命中率"**（核心概率口径，F-BT-08） |
| 分组 | 分年度、分牛熊市况、分行业的表现拆解 |
| 可视化 | 资金曲线、回撤曲线、与基准对比曲线 |

### 9.5 稳健性测试
- **参数敏感性**：关键参数（均线周期、放量倍数、持有期、Top N）小幅变动，绩效是否稳定。
- **样本内/外**：训练区间定参，独立验证区间检验。
- **基准对照**：与"随机选 N 只""全市场等权"对照，确认超额来自策略而非贝塔。

- 退市股历史数据**完整保留**。
- 关键字段（OHLCV、流通股本）**非空校验**通过。

## 14. 风险、假设与待确认问题

### 14.1 主要风险

| 风险 | 说明 | 应对 |
|------|------|------|
| **过拟合** | 规则/权重贴合历史、样本外失效 | 样本内外切分、参数敏感性测试、保持规则简洁 |
| **未来函数** | 回测虚高、实盘落空 | 严格时点隔离、代码评审、构造样例校验 |
| **幸存者偏差** | 只测存续股导致结论偏乐观 | 保留退市股全量历史 |
| **数据质量** | 复权错误、缺失、异常值 | 数据质检模块 + 抽样人工核对 |
| **数据源限制** | AKShare 等公开接口频率/稳定性限制 | 限流、重试、本地缓存、数据源可插拔 |
| **市场风格漂移** | 趋势策略在震荡/熊市失效 | 分市况回测、明确策略适用边界 |
| **流动性/涨跌停** | 选出的票实际买不进 | 回测计入涨跌停/停牌约束，开盘达涨停价不可买 |
| **ST 点时事实缺失/未发布** | 会改变历史 universe 与涨跌停撮合 | 统一读取 Baostock `isST` 落成的 `stock_st_status_daily`；缺失、非权威或刷新批次未发布时失败关闭 |

### 14.2 假设（已默认，若不符请指出）
1. 单用户、本地 macOS 单机运行，不涉及多用户/云部署。
2. 本期只做 A 股、日线、EOD（收盘后），不做盘中实时与自动交易。
3. 数据源首选 AKShare 等免费公开接口（覆盖同花顺级别常规数据），后续可切 Tushare/QMT；架构需支持数据源可插拔。
4. 技术指标默认基于前复权价格计算。
5. 系统只输出"评分/概率/形态标签"，不输出投资建议。

### 14.3 已确认决策（原待确认问题，现已落实，见第 0 章）

| 问题 | 结论 |
|------|------|
| 历史数据深度 | 近 5 年 |
| 北交所 / 科创板 | 含科创板，不含北交所；主板+创业板+科创板 |
| "上涨概率"口径 | 买入后 N 日内涨幅 ≥ X% 的概率（X、N 可配） |
| 资金流维度 | MVP 不做 |
| 卖出规则 | 默认跌破均线（MA20）卖出，可叠加持有期/止盈止损 |
| 使用形态 | Web/桌面可视化界面 |
| 数据源/账号 | 暂无高积分 Tushare 账号，第一版以 AKShare 等免费接口为主，取同花顺级别数据 |

### 14.4 已全部确认（详见第 0 章）

| 项 | 结论 |
|----|------|
| 涨幅命中口径 | 主口径 N=20 日、X=10%；多档 N∈{5,10,20,60}、X∈{10%,20%,30%} |
| 次新股处理 | <60 交易日硬剔除；<480 日长周期指标判"不适用" |
| 界面形态 | 本地 Web，单用户免登录，ECharts 图表 |
| 回测基准 | 主对照中证 500，并列示沪深 300、中证全指(000985) |

仅剩一项在系统设计阶段顺带定：**是否默认剔除一字涨停板**（建议默认剔除，因当日买不进，回测无意义）。
