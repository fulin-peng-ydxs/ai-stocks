# 需求：榜单页「默认加载方案」

归档状态：已归档

> 来源：用户截图驱动需求（榜单页 + 浏览评分方案抽屉，红框标「设为默认加载方案」按钮）。

## 用户原话

「页面进来，默认首先是没有方案的，在抽屉资产中可以选择方案，将方案设置为默认加载方案，后面用户进来就能根据选择的默认加载方案直接装载到下拉框（前提：没有自己的评分方案时），是这样一个需求！」

## 需求拆解

| 编号 | 需求 | 验收 |
|------|------|------|
| R1 | 资产抽屉行操作新增「设为默认加载方案」 | 仅榜单页评分方案抽屉出现；其它消费页（筛选/配置/个股详情/回测）不显示 |
| R2 | 默认单值互斥 | 同一时刻至多一个默认；改设后旧默认行自动复原；可取消默认 |
| R3 | 默认偏好持久化 | 复用 `user_preference` 通道，跨刷新/跨设备生效；不新建表/端点/权限 |
| R4 | 进入自动装载（前提：没有自己的方案） | 进榜单页且 mine 列表为空时，自动把默认方案装进下拉框并刷新榜单 |
| R5 | 有自己的方案时默认不生效 | 维持现状「自动选中我的第一个」，默认偏好被忽略（不删除） |
| R6 | 默认方案失效兜底 | 被取消公开/删除后自动清偏好 + 提示，落回空态，不再每次报错 |
| R7 | 不触发 ElSelect 递归陷阱 | 装载复用 selectLoaded 已验证链路 |

## 边界

- 默认只能来自抽屉可浏览的 preset/tenant/public（不含 mine），天然是可见资产。
- 无 `board:view` 权限：不渲染搜索入口、不装载默认。
