# 个股 ST 状态统一展示闭环

归档状态：已归档

## 目标

所有会影响研究、选择、交易和复盘判断的股票列表，都在股票身份旁显式展示对应业务日期的 ST 状态；数据运维和身份隐藏场景不机械铺设标签。

## 展示规则

- `is_st=true` 时，在股票名称后显示紧凑危险语义描边标签 `ST`。
- `is_st=false` 时不显示“正常”标签。
- `is_st=null` 不得按非 ST 处理。业务决策链路继续失败关闭；允许降级的辅助选择器可显示中性“ST状态未知”。
- 标签优先跟随名称；名称不可见而代码可见时跟随代码；不新增独立 ST 列。
- 上层筛选或分组语义已经明确限定为纯 ST 集合时，行内不再重复显示 `ST` 标签；离开该限定上下文后恢复显示。
- 标签必须包含文字，不得仅依靠名称变色表达。
- 悬浮说明展示实际状态日期；历史结果不得使用当前状态装饰。
- ST 与退市是独立维度，可同时展示；不得根据股票名称中的 `ST`、`*ST` 或 `S*ST` 推断状态。
- 当前事实只有布尔 ST 状态，标签统一写 `ST`，不伪造更细风险警示类别。

## 日期口径

| 场景 | 状态日期 |
| --- | --- |
| 个股普通列表、分组列表 | 用户选择的交易日 |
| 每日榜单、评分、筛选结果 | 榜单或运行日期 |
| 板块成分股 | 页面行情截面日期 |
| 涨停梯队 | 天梯业务日期 |
| 回测每日榜单 | 选股信号日 |
| 回测逐笔交易 | 买入日 |
| 交易纪律 | 打卡交易日 |
| 个股详情 | 报价摘要对应交易日 |
| 业务股票搜索选择器 | 所属业务日期；无业务日期时取最新已发布交易日 |

接口统一允许返回 `is_st: boolean | null` 和 `st_as_of_date: string | null`。缺失状态不得强制转换为 `false`。

## 页面闭环

### 必须展示

- 个股查询普通列表和分组列表。
- 每日榜单、策略筛选、评分试算、回测当日榜单等共享排名结果。
- 板块历史成分股。
- 涨停梯队。
- 回测逐笔交易，标签说明为买入日状态。
- 交易纪律股票搜索、已选股票和历史操作快照。
- 个股详情头部继续展示，并消费同一展示规则。

### 不默认展示

- 数据概览逐股体检、数据质量问题、采集和调度范围、系统日志及数据字典。
- 纯股票代码批量输入控件。
- 盘感训练身份揭晓前。
- 图表对比队列等极窄辅助身份条。

数据治理页面若问题本身属于 ST，应由问题类型表达，不再叠加身份标签。盘感训练揭晓身份后可按训练截止日展示。

## 复用与生效

- 建立统一股票 ST 状态展示组件，集中管理显示条件、文案、日期说明、密度和无障碍语义。
- 现有股票名称单元格、排名表、卡片和股票选择器消费该能力；页面不得复制 `el-tag + is_st` 判断或维护私有颜色。
- 该标签属于事实标识，不提供用户显隐开关，不进入页面配置。
- ST 数据刷新或历史纠正后，动态列表在刷新时生效；榜单和天梯继续使用既有版本自检；回测交易按买入日期重新读取当前已发布的历史事实。

## 异常处理

- ST 发布状态为 `refreshing/failed` 时，依赖 ST 的榜单、筛选、回测和天梯继续失败关闭，不展示可能过期的标签。
- 对应日期缺少准确事实时，决策列表整体报错并提供重试；允许降级的辅助入口必须明确展示未知，不得伪装正常。
- 标签展示不改变任何既有权限；用户只有在原页面和数据可见时才能看到状态。

## 范围

### 必须实现

- 上述决策类股票列表统一显式标签和点时日期口径。
- 未知状态保持三态，不伪装为非 ST。
- 建立并消费统一展示能力。
- 更新 `DESIGN.md` 中“排名结果仅使用名称警示色”的旧规则及真实复用组件清单。

### 建议实现

- `本次纳入`：标签悬浮展示状态日期。
- `本次纳入`：业务股票搜索下拉同步显示标签。
- `后续建议`：数据源未来提供可靠风险警示类别后，再区分 `ST`、`*ST` 等类型。

### 暂不实现

- 用户自定义标签颜色或显隐。
- 按股票名称推断 ST 类型。
- 新增独立 ST 表格列。
- 在纯数据运维和系统管理页面全量铺设标签。

用户已确认按本闭环开发。没有阻塞确认项。
