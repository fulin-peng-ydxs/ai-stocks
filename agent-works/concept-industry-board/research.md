# 概念 / 行业板块数据源研究

## 1. 选型结论

板块数据使用同花顺公开页面和接口。它能在同一来源内提供板块字典、当前成分、板块指数和资金流，避免跨来源名称与口径混用。

适配器位于 `backend/datasource/ths_board.py`，服务编排位于 `backend/services/board_ingest.py`。板块数据是独立业务编排，不进入 AKShare / BaoStock 的个股 capability 选源链。

## 2. 已验证接口能力

| 能力 | 类型 | 返回特征 | 当前使用方式 |
| --- | --- | --- | --- |
| 板块字典 | 概念、行业 | 路径代码 + 名称 | 全量分页拉取并 upsert |
| 板块详情 | 概念、行业 | 页面隐藏 `clid` | 补齐 `app_code`，进程内按板块缓存 |
| 当前成分 | 概念、行业 | AJAX 分页，可能遇到登录墙 | 双排序策略取更完整结果，输出 `complete` |
| 指数日线 | 概念、行业 | `d.10jqka.com.cn` 年度 JS | 按年份解析原始连续指数 |
| 资金流 | 概念、行业 | 即时 / 3日 / 5日 / 10日 / 20日 | 按类型和周期采集 |

请求需要同花顺 `v` cookie。适配器优先生成动态 cookie；可通过 `AI_STOCKS_THS_COOKIE` 或 `AI_STOCKS_THS_COOKIE_FILE` 提供登录态。cookie 不持久化、不输出到日志。

## 3. 双代码体系

同花顺概念板块存在两套代码：

- 路径代码：Web 详情、分类跳转和现有取数路径使用，例如 AI PC `309121`；
- App clid：详情页隐藏字段，手机 App 可见，例如 AI PC `886071`。

`board_code` 使用路径代码作为主键；`board_dict.app_code` 保存 clid。行业板块的两套代码通常相同。clid 获取失败不应丢弃字典主体；后续字典采集只补缺失值，避免反复请求。

## 4. 已知限制与工程处理

### 当前成分不可历史回溯

源端只提供当前成分，无法证明一只股票何时退出。当前模型因此采用“只进不出”：只要股票在某次完整快照出现，就永久保留 `(board_code, code)` 关系。它表达“自系统接入以来曾出现过”，不表达任意历史日期的精确成员集合。

`member_count` 单独保存最近完整源快照的当前数量，`member_snapshot_at` 保存成功时间。页面若展示 `board_member` 统计，必须称为累计成分关系，不能称为当前快照明细。

### 登录墙和分页截断

成分页面可能在后续页跳转登录页或返回非预期内容。适配器必须识别失败并返回 `complete=False`。服务层以完整性作为硬闸门：不完整、异常或空快照整块不落库。

### 指数历史有限且可能局部失败

年度接口实测主要保留近三年数据，2024 年以前可能返回 404。各板块上市时间不同，最早日期不必一致。某个请求年份失败时 DataFrame 通过 attrs 返回 `failed_years`，让服务保留成功年份但如实标记部分失败。

### 资金流只有名称

概念资金流没有可稳定作为主键的路径代码。当前按 `board_type + name` 精确匹配字典；字典外名称写 `board_fund_unmatched`，不生成伪代码、不建立只有资金流能力的虚假字典行。

资金流写入前校验：

```text
net_inflow = inflow - outflow
```

允许小数解析误差；净流入缺失时可由流入减流出补齐，明显不一致的行视为失败。

## 5. 稳定性策略

- 专属配置：`ths_board.min_interval_sec / timeout_sec / max_retries / retry_backoff_sec`；
- 请求按配置限速并指数退避重试；
- 字典类型、板块和资金流周期之间隔离失败；
- 所有写入使用唯一键 upsert 或冲突忽略；
- 同一运行内缓存 clid，避免字典、成分和指数阶段重复抓详情页；
- 资金流未匹配和成分不完整问题幂等创建；
- 更新日志保留失败范围，任务结果保留失败清单。

## 6. 数据量与性能判断

概念和行业合计为数百个板块。全量操作包括逐板块详情 / 成分页、逐板块逐年指数和十个资金流类型周期组合，是长任务，必须使用异步任务、写库互斥、分工作单元 checkpoint 和小批量验证参数。

业务读取侧只需要每个板块最近 21 个指数交易日即可计算 20 日涨幅。上涨 / 下跌家数应一次聚合全部目标板块，不应按板块循环查询。

## 7. 不能从源端保证的事项

- 接入前任意历史日期的精确成分集合；
- 资金流字典外名称对应的稳定路径代码；
- 所有板块拥有相同起始日期的指数历史；
- 公共页面永不触发登录墙或反爬变更。

这些限制通过保守不落库、质量台账、诚实失败、重试和显式数据日期暴露，不通过猜测数据来掩盖。
