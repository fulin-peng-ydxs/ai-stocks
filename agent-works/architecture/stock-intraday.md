# 个股日 K 下钻分时

## 功能边界

个股详情页和共享 `StockAnalysisPanel` 的 K 线模式允许点击日 K 蜡烛，按需打开对应交易日的分时弹窗。共享分析面板覆盖个股查询、每日榜单和连板天梯；板块行情、盘感训练和回测交易回放不启用下钻。

弹窗只有两个联动绘图区：上图为每分钟收盘价、当日累计均价和昨收参考线，下图为分钟成交量。价格左轴显示价格、右轴按昨收显示涨跌幅，量能数值轴使用左侧；午休时段不补点，图表连接源端实际返回的相邻分钟。系统仍是 EOD 产品，弹窗不轮询、不产生盘中日 K。

## 数据口径与接口

`GET /api/stocks/{code}/intraday?trade_date=YYYY-MM-DD` 复用 `stocks:view` 权限，返回 `frequency=1m` 及 `ready|partial|out_of_range|no_data` 业务状态。分钟点包含 `time/open/high/low/close/volume/amount/average_price`：

- 价格线使用分钟 `close`；`volume` 在接口、缓存和页面中固定为手（1 手 = 100 股），新浪源由股除以 100，东财源原值即为手；
- 累计均价由服务端按当日累计成交额除以 `累计手数 × 100` 计算，不使用未来分钟；
- 量柱优先按 `close >= open` 为上涨红、否则为下跌绿；东财历史分钟 `open=0` 时改用上一分钟收盘判断，首点无法判断时保持中性，不伪造开盘价；
- 昨收读取本地 `daily_bar.pre_close`；分钟价格始终不复权；
- 分钟点缺失时不补价格、不补成交量，保留真实点并返回 `partial`；
- 股票不存在、该股票当日没有本地日线或源端确认无数据返回 `no_data`；日期不在本地最新 8 个已入库交易日中返回 `out_of_range`；两者均不会访问外部分钟源；
- Redis、锁等待或外部源异常返回可重试 503，前端在弹窗内处理，不触发全局错误提示。

主源为新浪 1 分钟近期窗口，固定请求 1970 个分钟点；主源失败或为空时直连东财 1 分钟接口兜底，东财实际仅覆盖最近 5 个交易日。两个源都使用 `intraday.request_timeout_sec`，并在适配层完成手/元单位归一。Baostock 最小粒度为 5 分钟，不参与此功能，避免同一弹窗出现混合粒度。

## Redis 缓存与源站保护

分钟数据不写 DuckDB、PostgreSQL、文件或异步任务表。Redis 保存紧凑数组形式的“数据源 + 股票 + 1m”近期窗口，缓存版本 `v=2` 的成交量单位固定为手，旧版缓存自动忽略并重抓；非空窗口 TTL 为 43200 秒，同一股票随后点击不同近期日期直接筛选同一窗口。空响应和全部源失败分别使用 60 秒短缓存/负缓存，单载荷上限 2 MiB。

缓存未命中时，同股票使用 `SET NX EX` 单飞锁；等待者只轮询缓存或负缓存，最多 20 秒。锁值为随机令牌，释放使用 compare-and-delete Lua，不能删除其他请求持有的锁。所有股票和应用进程还共享一个 Redis 源站锁，免费分钟源请求全局并发固定为 1，相邻请求启动至少间隔 2 秒；单次请求超时 15 秒，每个源只退避重试 1 次。Redis 不可用时接口关闭失败，不绕开并发保护直连外部源。

相关配置位于 `config/settings.yaml` 的 `intraday` 段，仅作为项目配置，不进入管理页面。不得修改 Redis 全局淘汰策略；容量通过近期日期门禁、载荷上限和 TTL 控制。日志只记录缓存命中、锁等待、源名称、行数、耗时和失败类型，不记录完整分钟明细。

## 前端组件契约

`StockChartWorkspace` 的 `enableIntradayDrilldown` 默认关闭；开启后只处理 `candlestick` 系列单击并发出 `barClick(tradeDate)`。`StockIntradayDialog` 统一负责请求、取消、迟到响应隔离和业务状态，`StockIntradayChart` 统一生成双 grid ECharts 配置。两个入口通过 `useStockIntradayDrilldown` 共享打开、重复点击和切股关闭状态，不复制请求逻辑。

图表消费 `useStockChartTheme`：价格为主题主色，均价复用 MA5 身份色，昨收为中性虚线并只标 `0%`，量柱使用金融涨跌 token。价格纵轴以昨收为正中心按当日最大偏离上下对称展开，保证基准线始终可见；达到常见涨跌停边界时不再添加额外纵向留白。上下绘图区统一预留 64px 左右轴边界，保证价格和量能时间轴垂直对齐；日 K 工作区和分时共同消费 `app-stock-chart-frame` 外框、`StockChartPanelHeader` 标题栏、`StockChartLegend` 图例项，日线与分钟量柱共同消费 `buildStockVolumeBarSeries()`。上图显示“分时”及价格/均价图例，下图显示“量能”并使用共享双边分隔形态，禁止在 ECharts 画布或消费页另画标题、图例标识、边框或分隔线。两图按实际画布高度计算紧凑布局，底部时间轴固定展示 `09:30`、`11:30`、`15:00`，不把午休结束时间并入中间标签。弹窗顶部行情摘要消费 `StockQuoteSummary`：最新价作为无标签、适度强调的独立列，其余字段按每列最多三项紧凑排列，并与 K 线浮层共享 `StockQuoteSummaryModel`；旧 `.app-metric-*` 等宽指标网格已废弃。底部可见缩放条和画布内缩放同步价格/量能两图，尺寸或主题重绘时保留当前缩放范围。`partial` 在图表上方复用 `AppStatusNotice` 显示横向警告；范围、空数据和错误复用 `AppStateBlock`。关闭弹窗、切股、换日或重复点击都会取消/隔离旧请求，旧响应不得覆盖当前状态。

价格和量能绘图区均隐藏左右数值轴边框，水平网格线与日 K 统一为实线，只有昨收基准线保留虚线。

## 验证与运维

后端定向测试覆盖源字段归一、不复权参数、本地范围门禁、累计均价、缓存命中、空/失败短缓存、同股单飞、跨股票全局串行、Redis 关闭失败和 API 权限/503 映射。前端定向测试覆盖蜡烛事件、双绘图区/三序列、左右坐标映射、涨跌停边界、主题色、弹窗状态、取消与迟到响应，以及共享分析面板接入。

真实源冒烟只选择本地最新 8 个交易日内的股票日期，并确认第二次读取命中 Redis。公开免费接口可能临时限流或调整返回结构；发生 503 时先检查 Redis 连通性和服务日志，不通过提高并发或绕开缓存重试解决。
