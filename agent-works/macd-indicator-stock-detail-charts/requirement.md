# MACD 指标与个股详情多图联动需求文档

## 1. 背景与目标

「复盘啦」当前个股详情页可以展示日 K 线、均线和量能，但 K 线与量能被固定在同一个图表组件内，用户不能选择辅助图、隐藏辅助图或调整各图高度；系统统一技术指标体系中也尚未提供 MACD。

本需求继承并展开已确认的 [需求闭环](requirement-closure.md)，目标是：

- 建立 DIFF、DEA、MACD 柱、金叉、死叉五个 MACD 原子结果的统一定义和动态计算能力。
- 让五个原子结果进入现有指标目录、筛选、评分和买卖方案，保持下游使用同一口径。
- 将个股详情行情区升级为 K 线、量能、MACD 三图联动工作区，每幅图有明确名称和光标当前值。
- 支持用户配置两个辅助图的类型、顺序和显隐，并拖动分隔线调整图表高度。
- 将图表组合和相对高度保存为当前用户的页面偏好，支持跨个股、刷新、重新登录和跨设备恢复。
- 复用现有页面、权限、动态指标引擎、页面设置抽屉和用户偏好体系，不新增平行配置系统。

本需求已确认采用完整开放方案；没有阻塞或遗留确认项。

## 2. 当前项目现状

### 2.1 个股详情与图表

- 页面入口为 `frontend/src/views/StockDetailView.vue`，路由为 `/stocks/:code`，页面已通过 `LayoutHost` 使用 `stock-detail` 的 `detail` 原型。
- 页面使用 `getBars()` 加载行情、使用 `getIndicators()` 加载最新指标快照，主请求通过 `Promise.all` 汇总。
- 当前 `detailDefaults` 已保存复权方式、导航条和买卖评估卡显隐；指标快照原先只有字段显隐，没有整块模块显隐；也没有图表类型、辅助图显隐或高度比例。
- `frontend/src/components/CandleChart.vue` 在单个 ECharts 实例中固定声明两个 `grid`：
  - 第一网格展示 K 线与 MA5/10/20/30/60。
  - 第二网格展示成交量与 VMA5/VMA10。
- 当前图表已有共享 `axisPointer`、内部缩放、日期轴、主题适配、K 线 tooltip 和量能图例，可作为多图联动改造基础。
- 当前图表整体高度固定为 480px，量能标题位置依赖固定像素，不能直接承载可显隐、可换位和可拖动高度的三图结构。

### 2.2 指标定义与计算

- `backend/indicators/registry.py` 是内置指标元数据事实源，定义指标 key、中文名、数值类型、分类、方向、参数、说明、启停状态和表达式类型。
- `backend/indicators/definition.py` 将内置定义幂等写入 `indicator_def`，保留管理员对启停与分类的已有调整。
- `backend/indicators/operators.py` 当前提供 MA、HHV、LLV、REF、COUNT 等严格后向算子，尚无 EMA。
- `backend/indicators/compute.py` 提供单股和全市场两条动态计算路径；两者必须输出一致列。
- `backend/indicators/engine.py` 通过 `_IND_COLS` 固定动态指标帧列，供个股序列、宽快照、筛选、评分、买卖方案和回测复用。
- 技术指标使用前复权日线动态计算，不存在指标值落库表。
- `backend/screening/expression.py` 的表达式 DSL 尚未开放 EMA，现有自定义表达式无法可靠形成完整 MACD 指标组。
- 当前代码和测试中未发现 MACD、DIFF、DEA 或 EMA 定义。

### 2.3 现有接口与下游

- `GET /api/indicators/registry` 返回内置和自定义指标目录，普通业务用户通过 `indicator:registry` 读取，平台系统管理员通过 `indicator:def-manage` 管理定义。
- `GET /api/stocks/{code}/indicators?lookback=` 通过 `IndicatorEngine.compute_series()` 返回单股指标序列，使用 `stocks:view` 权限。
- `frontend/src/views/ConfigView.vue`、`ScreenView.vue`、`BoardView.vue` 以及评分、买卖方案相关逻辑均消费统一指标目录。
- 数值型指标可进入阈值筛选和评分规则；布尔型指标可进入筛选、评分和买卖条件树。

### 2.4 页面偏好与权限

- `frontend/src/composables/usePageSettings.ts` 基于 `useUserPreference` 保存页面级业务偏好。
- `useUserPreference` 已具备默认值与旧值递归合并、PostgreSQL `user_preference` 远端保存、localStorage 降级、远端加载前脏写保护、自动延迟保存和恢复默认。
- `backend/storage/user_preference.py` 按 `tenant_id + owner_user_id + scope + page_key + pref_key` 隔离偏好，归属来自请求上下文。
- 本需求可以复用 `scope=page`、`pageKey=stock-detail`、`prefKey=settings`，不需要新增数据库表或 DDL。
- 页面查看、指标目录读取、指标管理和用户偏好保存均已有权限码，本需求不新增资源 seed、菜单 seed 或路由权限。

### 2.5 设计与测试约束

- `DESIGN.md` 要求页面业务偏好复用 `usePageSettings` / `useUserPreference`，页面设置统一使用 `PageSettingsDrawer`。
- 个股详情已登记为 `detail` 原型，页面布局和设置抽屉不得绕过 `LayoutHost` 或建立第二套配置入口。
- 更新既有页面但涉及复杂图表、跨组件联动、设置和可视化状态时，应提供更新后原型。
- 当前长期 E2E 已覆盖页面设置抽屉通用链路，但未发现个股详情多图、辅助图显隐或拖动高度的专项用例。
- 本需求涉及真实点击、拖动、跨用户偏好和恢复默认，开发时必须补充或扩展 Playwright E2E。

## 3. 用户角色与使用场景

### 3.1 角色与权限

| 角色/权限 | 可执行能力 | 数据范围 |
| --- | --- | --- |
| 拥有 `stocks:view` 的登录用户 | 查看个股日 K 线、量能、MACD 和五个原子结果的个股序列 | 市场公共行情 |
| 拥有 `indicator:registry` 的登录用户 | 在筛选、评分、买卖方案中选择已启用的 MACD 原子指标 | 当前可见业务资产及公共指标目录 |
| 拥有 `user-preference:manage` 的登录用户 | 保存自己的图表类型、显隐和高度偏好 | 仅当前 `tenant_id + owner_user_id` |
| 拥有 `indicator:def-manage` 的平台系统管理员 | 启停内置 MACD 原子指标、调整分类 | 平台指标定义 |

### 3.2 典型使用场景

1. 用户从个股列表、分组、榜单或相邻个股导航进入详情，同时观察价格、成交量和趋势动能。
2. 用户只关注 K 线和 MACD，在设置抽屉隐藏量能并把更多空间分配给 K 线。
3. 用户希望 MACD 位于量能上方，在设置抽屉把图表二改为 MACD，系统自动把量能交换到图表三。
4. 用户拖动分隔线增大 MACD 高度；切换其他股票或刷新后继续使用该比例。
5. 用户在筛选方案中使用“MACD 金叉为真”，在评分规则中使用 MACD 柱值，在买卖方案中使用死叉作为卖出条件。
6. 新上市股票历史数据不足时，用户仍能查看已有 K 线，MACD 面板明确提示尚未形成有效值。

## 5. 详细功能需求

### 5.1 R1：EMA 与三个数值原子结果

- 功能描述：新增严格后向 EMA 算子，以及 `macd_diff`、`macd_dea`、`macd_hist` 三个数值型内置指标；参数固定为 12、26、9。
- 计算口径：
  - EMA 递推权重 `α = 2 / (n + 1)`。
  - `DIFF = EMA(C,12) - EMA(C,26)`。
  - `DEA = EMA(DIFF,9)`。
  - `MACD柱 = 2 × (DIFF - DEA)`。
  - EMA 采用递推口径，等价于 pandas `ewm(span=n, adjust=False, min_periods=n).mean()`。
  - 单股与全市场向量化路径必须使用相同算法和暖机规则。
- 前置条件：输入按股票、交易日升序，收盘价使用项目统一的前复权行情。
- 输入输出：输入前复权收盘价序列；输出与输入索引对齐的 DIFF、DEA、MACD柱数值序列。
- 校验规则：
  - EMA12 未满 12 日、EMA26 未满 26 日时输出空值。
  - DEA 未获得 9 个有效 DIFF 前输出空值。
  - MACD柱在 DIFF、DEA 任一为空时输出空值。
  - 不允许使用负向 shift 或任何 T 日之后数据。
- 异常情况：缺失收盘价不补造数值；NaN、无穷值在接口序列化前转换为 `null`。
- 权限与数据范围：指标动态计算本身不新增权限；全市场计算继续使用点时股票池和现有行情数据范围。
- 对现有功能的影响：`compute_stock_indicators()`、`compute_market_indicators()`、`_IND_COLS` 和参数哈希需同步包含新结果。

### 5.2 R2：金叉、死叉两个布尔原子结果

- 功能描述：新增 `macd_golden_cross` 与 `macd_dead_cross` 两个布尔型内置指标。
- 计算口径：
  - 金叉：当日 `DIFF > DEA`，前一有效交易日 `DIFF <= DEA`。
  - 死叉：当日 `DIFF < DEA`，前一有效交易日 `DIFF >= DEA`。
  - 只比较同一股票相邻有效交易日，不跨股票、不跨缺失段串联。
- 前置条件：当日及前一交易日 DIFF、DEA 均有效。
- 输入输出：输入 DIFF、DEA 序列；输出可空布尔序列。
- 校验规则：
  - 相等后向上突破属于金叉，相等后向下突破属于死叉。
  - 同一天不能同时为金叉和死叉。
  - 暖机不足或前一日无有效值时输出空值，不冒充未触发。
- 异常情况：下游布尔条件求值时，空值按“不成立”处理，但接口和原始指标序列仍保留 `null` 语义。
- 权限与数据范围：与 R1 相同。
- 对现有功能的影响：下游条件树、评分布尔项和接口序列化必须兼容 pandas 可空布尔。

### 5.3 R3：统一指标目录与既有下游接入

- 功能描述：
  - 将五个原子结果注册为默认启用、不可删除的内置指标。
  - 五个指标的主分类为“趋势”，预设多分类标签为“趋势”“动量”；数值指标不预设单向高低优劣，方向为 `None`。
  - 五个原子结果进入指标管理、筛选、评分和买卖方案选择列表。
- 建议显示名称：
  - `macd_diff`：MACD DIFF。
  - `macd_dea`：MACD DEA。
  - `macd_hist`：MACD柱。
  - `macd_golden_cross`：MACD金叉。
  - `macd_dead_cross`：MACD死叉。
- 操作流程：
  1. 系统启动或初始化时幂等 seed 五个内置定义。
  2. 普通用户读取启用指标目录并在业务方案中选择。
  3. 下游通过统一指标引擎获得数值或布尔结果。
  4. 平台系统管理员可按现有能力停用或调整分类，但不可删除。
- 校验规则：
  - 三个数值指标 dtype 为 `number`，两个交叉指标 dtype 为 `bool`。
  - 固定参数必须在描述中明确，不提供方案级参数输入。
  - 内置 key 不得被自定义指标覆盖。
- 异常情况：
  - 指标被停用后不出现在新建方案选择列表。
  - 已有方案引用已停用指标时，沿用现有兼容策略显示原定义和停用提示，不静默删除或改写方案。
- 权限与数据范围：读取使用 `indicator:registry`，管理使用 `indicator:def-manage`；不新增资源、菜单或默认角色授权。
- 对现有功能的影响：
  - `ConfigView`、`ScreenView`、`BoardView` 和买卖方案的目录消费应自然出现五个指标。
  - 指标管理中的技术标识使用等宽字体，并为长 key 提供足够列宽与溢出提示，`macd_golden_cross`、`macd_dead_cross` 不得无提示截断。
  - 评分规则允许对三个数值指标自定义阈值或区间，不强制“越高越好”。

### 5.4 R4：个股 MACD 序列查询与日期对齐

- 功能描述：个股详情按已加载行情范围获得五个 MACD 原子字段的历史序列；优先扩展现有 `GET /api/stocks/{code}/indicators`，不建立第二套 MACD 计算接口。
- 操作流程：
  1. 页面确定行情 `lookback`，包含展示区和指标暖机数据。
  2. 行情与指标序列并行加载。
  3. 指标接口返回所需 MACD 字段和交易日。
  4. 前端按 `trade_date` 与可见行情对齐，不按数组位置盲目拼接。
- 响应记录至少包含：`trade_date`、`macd_diff`、`macd_dea`、`macd_hist`、`macd_golden_cross`、`macd_dead_cross`。
- 校验规则：
  - 可选字段参数必须使用服务端白名单，不能直接拼接未校验字段。
  - 未传字段参数时保持当前接口兼容，不破坏现有调用方。
  - 为 `lookback` 新增合理上下限校验；“全部”模式复用当前页面最大加载边界。
  - 指标使用前复权口径，与 K 线当前复权模式解耦。
- 异常情况：
  - 指标请求失败时只使 MACD 面板进入错误态；K 线和量能继续使用。
  - 某些交易日指标为空时保留空点，不跨空值绘线或制造交叉。
  - 股票无行情时沿用个股详情整体空态。
- 权限与数据范围：使用现有 `stocks:view`；只读 DuckDB 行情和动态指标，不写指标值表。
- 对现有功能的影响：
  - 最新指标快照仍从同一接口获得，不重复计算同一范围。
  - 页面请求协调需避免较慢旧响应覆盖切换个股、区间或复权后的新响应。

### 5.5 R5：个股详情三图联动与图表命名

- 功能描述：将固定双网格升级为一个主图和两个辅助图槽组成的连续多图工作区；每幅可见图始终显示名称、参数和当前光标交易日核心值。
- 默认展示：
  - 图表一：`K线（日线·当前复权方式）`。
  - 图表二：`量能`。
  - 图表三：`MACD（12,26,9·前复权）`。
- 操作流程：
  1. 用户进入个股详情，页面恢复个人图表组合。
  2. 用户移动光标时，三图定位相同交易日并更新标题值。
  3. 用户缩放、拖动时间轴或切换 K 线范围时，所有可见图使用相同窗口。
- 图表内容：
  - K 线：蜡烛、现有均线和唯一的行情 tooltip；tooltip 固定在 K 线绘图区左上角，不跟随鼠标遮挡蜡烛。
  - 量能：涨跌色成交量柱、VMA5、VMA10。
  - MACD：红绿柱、DIFF、DEA、零轴，以及带交易日引导线的金叉和死叉标记。
  - 三幅图的柱体宽度必须体现主次层级：K线最宽、量能明显收窄、MACD柱最窄；推荐比例为 K线 `72%`、量能 `44%`、MACD `24%`，并分别限制最大宽度为 `18px`、`12px`、`7px`。
- 颜色口径：
  - A 股红涨绿跌。
  - MACD柱 `>=0` 使用上涨红，`<0` 使用下跌绿。
  - 股票指标序列色以盘感训练既有色板为唯一事实源：MA5 灰白、MA10 橙黄、MA20 洋红、MA30 青色、MA60 橙红；VMA5 橙黄、VMA10 青色；DIFF 橙黄、DEA 青色。盘感训练、回测和个股详情不得分别维护第二套色值；浅色主题使用同色相的加深版本，暗色主题使用高亮版本，保证 11px 标题值和细折线在实际画布背景下保持可辨。
  - K线与量能均线的周期、标题、ECharts 系列名和色板键必须分别由类型化 `KLINE_MA_DEFINITIONS`、`VOLUME_MA_DEFINITIONS` 唯一声明；兼容图表、三图序列和标题指标不得复制周期数组或标签映射。
  - 指标标题数值与实际折线必须消费同一共享色板；序列身份色不表达涨跌方向。
  - K 线 tooltip 的收盘价与涨幅按相对昨收使用 `--market-up-color` / `--market-down-color`；平盘或昨收缺失时使用中性文字色。
  - 每个标题指标值必须与其实际折线或柱体使用同一套主题调色映射；坐标轴数值保持中性文字色，不伪装成某条序列颜色。
- 校验规则：
  - 图名在 ready、loading、empty、error 状态下均保留。
  - MACD 标题随光标显示 MACD、DIFF、DEA；没有有效值时显示 `--`。
  - 金叉、死叉标记只能出现在 R2 为真的交易日。
  - 每个金叉、死叉标签必须常驻一条竖向引导线；标签中心、引导线和事件交易日使用同一 X 坐标，引导线末端锚定当日 DIFF 数据点，使用户无需移动光标也能判断信号所属交易日。
  - 标签因边界或密集信号需要避让时，只允许上下调整；不得横向偏移到其他交易日。相邻交易日标签仍冲突时可分层展示，但每条引导线必须保留各自事件日锚点。
  - 信号标签或锚点悬停提示至少显示信号类型和完整交易日期；不得用相邻两日折线之间的几何交点替代 R2 定义的事件交易日。
  - 金叉标签、引导线和锚点复用 `var(--market-up-color)`；死叉复用 `var(--market-down-color)`，与项目 A 股“红涨绿跌”口径及 MACD 柱方向保持一致。页面不得直接写红绿 hex，也不新增金色信号 token。
  - 颜色只表达多空方向；信号标签使用主题中性表面和高对比中性文字，标签轮廓、锚点和引导线使用涨跌方向色；“金叉/死叉”文字、轮廓、锚点和引导线共同表达事件类型。即使无法区分红绿，用户仍应能判断信号类型和所属交易日。
  - 日期轴和缩放控件放在最下方可见图，日期标签必须完整位于缩放滑块上方，首尾日期不得被画布或滑块裁切、遮挡。
  - 光标轴的选中交易日气泡只允许在 K 线面板显示一次；量能和 MACD 继续定位同一交易日并更新指标值，但不得重复显示日期气泡或标题日期。K线行情 tooltip 中的“时间”字段继续保留。
  - 所有可见图共享日期索引和同一缩放窗口；任一图通过 inside 或 slider 改变 `start/end` 后，组件必须显式同步到其余可见图，重新渲染或主题重绘不得重置该窗口。
  - 量能不显示内容 tooltip；MACD 普通柱线不显示内容 tooltip，只有信号标签或锚点在 item 悬停时显示“信号类型 + 完整交易日期”。二者仍保留共享十字光标、交易日定位和标题当前值，避免三幅行情浮层同时遮挡数据。
- 状态变化：切换个股只替换数据，不重置图表类型、顺序、高度或当前 K 线范围偏好。
- 权限与数据范围：使用 `stocks:view`；图表数据是公共行情。
- 对现有功能的影响：指标快照、集合导航和买卖信号评估卡位置及职责不变；页面继续使用 `detail` 原型。

### 5.6 R6：辅助图类型选择、自动交换和隐藏

- 功能描述：
  - 图表一固定为 K 线，不允许切换或隐藏。
  - 图表二、图表三均支持 `量能`、`MACD`、`隐藏`。
- 对应入口：个股详情页面设置抽屉“业务选项 → 图表设置”。
- 操作流程：
  1. 用户打开设置抽屉。
  2. 用户选择图表二或图表三类型。
  3. 页面即时更新并自动保存，不增加提交按钮。
- 自动交换规则：
  - 两个辅助图不能同时选择相同可见类型。
  - 目标类型已被另一辅助图使用时，另一辅助图自动切换为当前槽位修改前的类型。
  - 当前槽位修改前为“隐藏”时，另一辅助图随交换变为“隐藏”。
- 显隐规则：
  - 隐藏后不保留空白面板和无效分隔线。
  - 剩余图表使用释放空间。
  - 重新显示时恢复该组合最近有效高度；不存在时使用默认比例。
- 校验规则：非法枚举、重复可见类型或图表一非 K 线均回退为有效组合；至少保留 K 线。
- 权限与数据范围：只修改当前用户页面偏好。
- 对现有功能的影响：继续复用 `PageSettingsDrawer` 和 `PageSegmented`，不得新增第二个设置抽屉。

### 5.7 R7：图表高度拖动与键盘调整

- 功能描述：相邻可见图表之间提供分隔线，支持拖动调整两侧高度；分隔线可聚焦并支持方向键小步调整。
- 默认高度：
  - 三图可见：`60% : 20% : 20%`。
  - K 线 + 一个辅助图：`75% : 25%`。
  - 仅 K 线：占满图表工作区。
- 操作流程：
  1. 用户按下分隔线并拖动。
  2. 相邻图表实时改变高度并同步 resize。
  3. 达到最低高度后停止继续压缩。
  4. 释放后保存相对比例。
  5. 分隔线聚焦时，`↑/↓` 以约 2% 步长调整。
- 最低高度：
  - K 线面板最低 250px。
  - 量能或 MACD 辅助面板最低 126px。
  - 三图默认工作区提供不少于 650px 的可用高度。
- 校验规则：
  - 高度保存为相对比例，不保存固定像素。
  - 比例为有限正数，当前可见图归一化之和为 1。
  - 不允许拖到零高度；隐藏必须通过设置抽屉。
  - 拖动期间不刷新行情、不重置光标或缩放范围。
  - 窗口变化导致的临时像素收敛不能覆盖用户正常比例。
- 异常情况：可用高度不足时保持图表最低总高度并由页面区域滚动。
- 对现有功能的影响：图表 resize 与窗口 resize、KeepAlive 激活/停用机制兼容。

### 5.8 R8：图表组合与高度个人偏好

- 功能描述：图表二类型、图表三类型和各可见组合最近有效高度比例保存到当前 `stock-detail` 页面偏好。
- 配置闭环：
  - 谁定义：个股详情页面声明产品默认值。
  - 谁渲染：图表工作区和页面设置抽屉。
  - 谁保存：`usePageSettings` / `useUserPreference`。
  - 保存位置：PG `user_preference`，`scope=page`、`pageKey=stock-detail`、`prefKey=settings`；localStorage 仅作降级。
  - 谁读取：个股详情页面实例。
  - 谁消费：辅助图渲染、分隔线布局和恢复默认逻辑。
  - 谁校验：前端归一化类型与比例，后端校验 JSON、大小和当前用户归属。
- 建议偏好结构：

    {
      "charts": {
        "slot2": "volume",
        "slot3": "macd",
        "heightRatios": {
          "kline|volume|macd": [0.6, 0.2, 0.2],
          "kline|macd|volume": [0.6, 0.2, 0.2],
          "kline|volume": [0.75, 0.25],
          "kline|macd": [0.75, 0.25]
        }
      }
    }

- 说明：组合 key 包含可见类型和顺序；实际字段名可在开发计划中按现有类型约束微调，但必须保持业务语义。
- 生效时机：
  - 类型和显隐修改后即时生效并延迟自动保存。
  - 高度拖动期间只更新页面状态，释放后保存，避免高频远端写入。
- 失效与回退：
  - 无登录态或接口失败时使用本地回退。
  - 远端无记录时使用默认值。
  - 旧偏好不含 `charts` 时递归合并新默认值，无需数据迁移。
  - 非法枚举、重复类型、负数、NaN、无穷或比例和异常时回退对应默认组合。
- 恢复默认：
  - 图表二=量能、图表三=MACD。
  - 清除所有自定义组合高度并恢复默认比例。
  - 与页面布局用户层和设置抽屉自身偏好的重置继续按 `PageSettingsDrawer` 现有整体规则执行。
- 权限与数据范围：后端只接受请求上下文归属，禁止前端传 `tenant_id` 或 `owner_user_id`。
- 对现有功能的影响：偏好字段是 JSON additive 变更，不新增表或 SQL。

### 5.9 R9：页面状态与局部失败隔离

- 功能描述：完成三图工作区在加载、空数据、局部错误和权限不足时的分层反馈，避免 MACD 问题连带阻断仍可用的 K线或量能。
- ready：图名、当前值、图形、分隔线和共享光标均可用。
- loading：
  - 初次行情加载使用页面现有加载态。
  - MACD 独立加载时保留图名和稳定占位，不让高度跳变。
- empty：
  - 股票无行情时显示个股行情空态。
  - 历史不足时提示“历史数据不足，暂不能形成完整 MACD”，不显示零值或假交叉。
- error：
  - 行情整体失败使用页面级错误与重试。
  - MACD 独立失败只在 MACD 面板显示局部错误和重试，K 线、量能保持可用。
  - 偏好远端失败按现有逻辑本地降级；显式错误提示留 R10。
- 权限不足：
  - 无 `stocks:view` 沿用 403 处理，不伪装为空数据。
  - 无偏好管理权限不阻断公共行情查看。

### 5.10 R15：图表工作区响应式、主题与可访问性

- 功能描述：保证多图工作区在关键视口、明暗主题及鼠标、触控和键盘输入下保持可读、可操作。
- 响应式：
  - 图表始终纵向排列，不在窄视口改成左右并排。
  - 标题可减少次要项，但图名、核心值和最低高度必须保留。
  - 图表工作区由 `StockDetailView` 的正常文档流提供最低 650px 内容高度，并自动填满当前主内容区扣除可见下方辅助模块后的剩余高度；隐藏指标快照或买卖评估卡后，释放的空间必须即时回到图表工作区，不保留固定空白。
  - 最新指标快照和买卖评估卡都作为可独立显隐的辅助模块，由页面设置抽屉控制；指标快照默认显示，旧偏好缺少该字段时递归合并为显示。
  - 工作区与可见辅助模块继续顺序排布，短视口不足时保持最低高度并由 `LayoutHost` 主区承担滚动。
  - 业务视图和组件不得使用 `calc(100vh - Npx)`、固定视口减法或第二套内部整页滚动计算。
- 主题：复用现有主题和语义色；`CandleChart` 与 `StockChartWorkspace` 只通过 `useStockChartTheme()` 消费明暗、预设 key 和同 key 后端覆盖后的响应式股票画布主题，不分别组合底层主题依赖；柱、折线、网格、文字、分隔线和金叉/死叉标记在明暗主题下均可辨识。
- 输入：拖动使用 pointer 事件覆盖鼠标与触控；分隔线具备 `role=separator`、水平朝向和值语义，并支持方向键调整。
- 可访问性：
  - 图表标题的光标跟随指标值不得设置 `aria-live`，避免指针移动时形成三组高频播报；后续如需播报，只能由键盘或明确聚焦触发一个节流后的专用区域。
  - 图表二、图表三的分段选项必须提供程序化选中语义；复用 `PageSegmented` 时每个按钮使用 `aria-pressed` 表达当前值，并为两组控件提供可访问名称。
- 动效：尊重 `prefers-reduced-motion`，关闭非必要过渡但不影响状态反馈。

### 5.11 R16：兼容回退与请求竞态保护

- 功能描述：保证新增字段、旧偏好、非法偏好、快速切换和 KeepAlive 生命周期不会破坏现有页面或产生状态回写。
- 接口兼容：
  - 路由、集合导航、指标快照、买卖评估和复权设置保持可用。
  - 现有指标接口调用方在不传新增字段参数时行为不变。
- 偏好兼容：旧值没有 `charts` 时递归合并默认值；非法类型、重复类型或非法比例只回退对应组合，不清空其他有效设置。
- 模块兼容：旧偏好没有 `showIndicatorSnapshot` 时默认显示；显隐修改与其他页面业务偏好走同一自动保存和恢复默认链路，不新增独立存储。
- 请求竞态：切换个股、区间或标签页时取消旧请求或校验请求序号，旧响应不得覆盖最新数据和状态。
- 生命周期：KeepAlive 恢复时重新 resize 和监听；停用或卸载时释放 chart、pointer、resize 监听，不重复创建实例。

## 6. 数据与接口需求

### 6.1 指标字段契约

| 字段 | 类型 | 口径 | 无效期 |
| --- | --- | --- | --- |
| `macd_diff` | number/null | EMA12 - EMA26 | EMA26 暖机完成前为 null |
| `macd_dea` | number/null | EMA9(DIFF) | 9 个有效 DIFF 前为 null |
| `macd_hist` | number/null | 2 × (DIFF - DEA) | DIFF/DEA 任一无效时为 null |
| `macd_golden_cross` | bool/null | DIFF 当日上穿 DEA | 当日或前一有效日不足时为 null |
| `macd_dead_cross` | bool/null | DIFF 当日下穿 DEA | 当日或前一有效日不足时为 null |

### 6.2 指标定义元数据

- 五字段均为 `builtin`、`is_builtin=true`、默认 `enabled=true`。
- 参数固定，不向方案暴露参数表单；描述写明 `(12,26,9)` 和前复权口径。
- 分类默认包含“趋势”“动量”；三个数值指标 `direction=None`。
- 指标 seed 幂等执行，保留管理员对同 key 的 enabled/categories 调整。

### 6.3 动态计算与缓存

- 不新增 MACD 值表，不写回 `daily_bar` 或复权因子字段。
- 单股和全市场结果逐行一致，允许浮点容差但不允许交叉日不同。
- `_IND_COLS`、宽快照和单次运行缓存纳入五个字段。
- MACD 暖机短于现有 MA250/HHV480，原则上不扩大引擎 `_max_lb`。
- 全市场路径向量化或按现有 groupby 方式计算，禁止每股独立查询。
- `param_hash` 或等价算法版本能区分新增计算口径，避免缓存语义不明。

### 6.4 个股指标接口

- 沿用 `GET /api/stocks/{code}/indicators` 和 `{code, indicators:[...]}` 外层结构。
- 可增加可选字段过滤参数；字段必须白名单化。
- 原有最新快照调用保持兼容。
- 序列化前把 pandas/NumPy 的 NaN、NA 和无穷转换为 JSON `null`。
- 页面按交易日合并行情和指标，不进行跨库 JOIN。

### 6.5 用户偏好

- 复用 PG `user_preference`，不新增 DDL 或 SQL。
- 主键和读写继续包含 `tenant_id + owner_user_id + scope + page_key + pref_key`。
- 前端保存值不携带归属字段。
- 高度只在拖动结束后远端保存，类型修改继续使用现有延迟保存。
- JSON 体积低于现有 64KB 上限。

## 8. 边界条件与异常场景

| 场景 | 处理要求 |
| --- | --- |
| 股票历史少于 EMA26/DEA 暖机长度 | 对应数值和交叉返回 null，MACD面板提示历史不足 |
| DIFF/DEA 中途存在空值 | 不跨空值连接折线，不跨缺失段判断金叉/死叉 |
| 图表二、三保存为相同类型 | 前端按自动交换规则归一化；无法判断旧值时回默认 |
| 图表一配置异常 | 强制恢复 K线且可见 |
| 两个辅助图都隐藏 | 仅 K线占满工作区，不显示分隔线 |
| 指标快照和买卖评估卡都隐藏 | 三图工作区自动填满主区剩余高度，不保留辅助卡空白 |
| 隐藏后重新显示 | 恢复相同类型顺序组合最近比例，没有则用默认比例 |
| 比例为负、零、NaN、无穷或和不为1 | 丢弃非法项，按可见组合默认比例恢复 |
| 浏览器窗口高度不足 | 保持图表最低总高度，由页面滚动，不压坏图表 |
| 拖动过程中切换个股 | 停止拖动并保存最后有效比例；数据请求独立切换 |
| 拖动过程中组件停用或关闭标签 | 清理全局 pointer 监听；只保存有效终态 |
| 远端偏好晚于用户操作返回 | dirty-before-hydrate 保护用户刚完成的修改 |
| 偏好保存失败 | 当前会话和本地继续生效；显式提示留 R10 |
| MACD接口失败 | MACD局部错误与重试；K线和量能继续使用 |
| 行情接口失败 | 页面级错误与重试 |
| 指标被管理员停用 | 新方案不再可选；已有引用显示停用状态，不静默删除 |
| 明暗主题切换 | 所有可见图重绘，颜色语义不变 |
| 任一图拖动缩放条或滚轮缩放 | 三图显式同步同一时间窗口，主题重绘后仍保持该窗口 |
| 快速切换个股/范围 | 取消旧请求或使用请求序号，旧响应不得覆盖新状态 |

## 9. 性能、安全与兼容性要求

### 9.1 性能

- 全市场 MACD 计算复用批量行情查询和向量化分组计算，不得形成按股票 N+1 查询。
- 单股详情只计算/返回当前股票和所需范围；可通过字段白名单减少响应体。
- 切换辅助图显隐不重复计算已加载 MACD。
- 拖动高度只更新布局和图表尺寸，不触发网络请求；远端偏好只在释放后写一次。
- window、pointer、chart 监听在组件停用或卸载时释放。
- KeepAlive 恢复时只重新监听和 resize，不重复创建未销毁实例。

### 9.2 安全与权限

- 指标和行情端点继续受现有权限保护。
- 可选字段参数只能从服务端白名单选择，禁止 SQL 字段注入。
- 用户偏好归属只来自请求上下文；查询和 upsert 保持 `tenant_id + owner_user_id` 条件。
- 不在 JWT 中新增指标或图表偏好，不信任前端传入角色、权限或归属。
- 本需求不写行情库，不修改原始复权因子。

### 9.3 数据一致性

- 单股与全市场 MACD 在相同股票、交易日和前复权行情下必须一致。
- 向未来追加行情不能改变历史交易日已有 MACD 值和交叉事件。
- 图表、筛选、评分和买卖方案使用同一五字段定义。
- K线复权方式变化只影响 K线展示；MACD保持前复权并在标题标识。

### 9.4 兼容性（R15、R16）

- 旧用户偏好没有 `charts` 字段时自动合并新默认值。
- 现有指标接口和 registry 外层结构保持兼容。
- 现有方案不引用新指标时结果不变。
- 重点验证 1100×620、1366×768、1440×900。
- 窄视口保持纵向图表和最低可读空间，不增加页面级横向滚动。
- 支持鼠标、触控 pointer 和键盘调整；尊重 reduced motion。

## 10. 业务亮点与优化建议

本次业务亮点是：同一 MACD 原子定义贯通“看图—筛选—评分—买卖条件”，同时把多图组合和高度沉淀为个人工作台偏好，避免页面展示与策略条件形成两套口径。

可执行的后续建议只在 §4.2 登记并维护处理状态，本节不重复登记 R10、R11，避免形成两个状态事实源。
